Рекомендуемый формат: data.bin — снимок из исходного сайта, уже рассчитанный по вашим Excel-правилам. Если в нём сохранены две публикации, достаточно загрузить его в поле «Текущий».

Также поддерживаются .csv и небольшие .xlsx с явной колонкой «Блок» и внутренним ID договора (например, экспорт общего реестра). Для обычного сырого реестра используйте отдельную кнопку Excel + правила. Файлы читаются на вашем устройстве, не отправляются в сеть.

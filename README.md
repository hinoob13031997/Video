# Moonvit — интерактивная концепция

`scenes.html` — самостоятельная версия без видео: шесть сгенерированных космических фонов и шесть концептуальных упаковок, плавные переходы, управление кнопками, стрелками клавиатуры и свайпом. Изображения вдохновлены референсом, но не совпадают с ним точно; упаковки не заменяют оригинальные макеты этикеток. Все визуальные ресурсы локальные. Исходные изображения в `assets/planet-backgrounds.png` и `assets/planet-products.png` организованы как сетка 3×2 и отображаются через CSS без дополнительной обработки.

Сайт по видеореференсу IMG_3195.mp4. Полноэкранный видеоряд, переключение между шестью планетами, фильтруемый каталог и адаптивная вёрстка. Каталог ведёт на официальный сайт; оформление заказа здесь не реализовано.

## Запуск

Из `/workspace/Video`:

```sh
python3 server.py
```

Зависимости для сборки не требуются. Шрифты загружаются из Google Fonts; без сети используются системные шрифты. Видео и кадры хранятся локально в `assets/`.

Видеореференс содержит встроенные надписи и элементы интерфейса. Для независимой анимации, чистой композиции на мобильных экранах и точного управления сценами понадобятся исходные видеосцены без интерфейса или 3D-модели. Текущая версия использует исходный ролик как фон с переключением времени воспроизведения.

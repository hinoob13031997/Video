# NEON FLOW V4 — Premium Workspace

Локальная аналитическая воронка: https://hinoob13031997.github.io/Video/

## Работа
- «Воронка»: вертикальный обзор, полная схема, поиск, масштаб под курсором, перетаскивание поля, мини-карта, скрытие других веток, локальное перемещение карточек.
- «Изменения»: сравнение двух снимков по внутреннему ID, отдельные неоднозначные и затронутые правилами изменения, анимация, режим показа, CSV.
- «Правила»: локальный редактор на исходном движке, добавление/удаление блоков, критерии и связи, выгрузка XLSX с дополнительным листом структуры NEON. Сохранённую таблицу применить при новом расчёте. Исходный сайт не изменяется.
- «Данные»: локальный импорт Excel + правила, рассчитанные BIN/JSON/CSV/XLSX, проверка ID, сохранение истории по команде, отчёты Excel.
- В панели блока: число строк, задолженность, состав, распределение по дочерним блокам и причины (если сохранены при расчёте). Суммы и количества могут пересекаться между блоками.
- Фильтры: дата смерти, сумма, цессии при наличии полей. Дата смерти не фильтрует корневой блок. Число строк и число уникальных ID — разные показатели; дубли исключаются из сопоставления переходов.
- История хранится в IndexedDB этого браузера, только после команды «Сохранить снимок». Демо запускается отдельно.

## Код
- index.html — интерфейс
- styles.css — одна система стилей V4, светлая/тёмная тема
- app.js — контроллер, схема, импорт и сравнение
- workspace.js — фильтры, статистика, распределение, история, экспорт XLSX
- engine.html — изолированный локальный исходный движок и редактор. computeSets сохранён без изменений.
- jszip.min.js — библиотека ZIP
- tests/workspace.test.cjs — контрольные проверки, запуск: node --test tests/workspace.test.cjs

## Безопасность и ограничения
Репозиторий публичный. Не публикуйте реестры, снимки, персональные данные, пароли или токены. Сохранение и обработка в браузере; библиотека SheetJS 0.18.5 хранится локально в vendor/. Публикация общих данных выключена. Для совместного доступа требуется защищённое хранилище и контроль доступа; открытый GitHub не подходит для реестров должников.
Проверки на синтетических данных и проверка неизменности computeSets не заменяют сверку всех блоков на реальном реестре. Тестирование полной рабочей выгрузки в браузере и безопасная многопользовательская инфраструктура остаются отдельными задачами.

## V4.4 — встроенный редактор

Раздел «Правила» открывает рабочее окно внутри V4.4. Редактор использует локальный интерфейс `rules-editor.js` и команды изолированного `engine.html`. Старый интерфейс больше не открывается отдельной вкладкой. Поддержаны критерии, родительские связи, источники, исключения, визуальные стрелки, импорт/экспорт Excel, локальные черновики и история последних 20 сохранённых правок. После сохранения для применения требуется успешный пересчёт исходных файлов. Новые рассчитанные снимки сохраняют полную конфигурацию; для старых снимков без конфигурации требуется импорт исходных правил. Проверены операции на исходной конфигурации из 49 блоков и защита от циклов. Полный браузерный тест с рабочим реестром остаётся отдельной задачей.


## V4.9 — локальная аналитика и устойчивость

- Сравнение и статистика реестров от 100 000 строк вынесены в analysis-worker.js. Импорт Excel и первоначальный расчёт по-прежнему выполняются исходным движком в локальном iframe. При сбое загрузки сохраняется предыдущее состояние.
- «Данные → Диагностика»: дубли, пропуски ID и сумм, пересечения, непокрытые дочерними блоками строки, простые противоречия критериев, проверка названий колонок, резкие изменения, баланс строк и ID. Предупреждение не всегда означает ошибку.
- «Данные → История договора» или клик ID: наблюдения по локальным снимкам. «Детали → Контроль застоя»: интервалы непрерывного наблюдаемого присутствия, не точная продолжительность этапа. Изменение подписей правил прерывает сопоставимый период.
- При повторном расчёте того же исходного файла с черновиком правил показывается предварительная таблица последствий, до подтверждения действующая воронка не заменяется.
- История: период, количество, задолженность, второй блок для сравнения; автоматическое сохранение по включаемой пользователем настройке. Дату снимка можно указать в форме загрузки. Предыдущий реестр сохраняется автоматически только при указанной дате. Снимки не передаются в сеть.
- Потоки по количеству/сумме, топ-10/25, только изменившиеся блоки; семантический масштаб, подсветка цепочки и создание визуальной связи выбором двух блоков. Настройки и локальные черновики можно скачать в JSON без реестра.
- SheetJS 0.18.5 vendored, лицензия Apache 2.0 в vendor/LICENSE-SheetJS.txt.
- Тесты: node --test tests/*.test.cjs. Проверки на синтетических данных не заменяют реальную проверку исходного Excel 607 117 строк.

Не реализовано: общий сервер данных с ролевой авторизацией, аудитом, резервным копированием и защищённым доступом сотрудников. ## V4.10 — рабочее полотно

Три режима карточек: договоры, задолженность, зоны внимания. Быстрые признаки (резкое изменение от 30% при базе от 20 строк, неоднозначные изменения, изменённые правила/фильтры, пропуски сумм) используют готовую аналитику. Дополнительная диагностика дочерних блоков запускается при открытии «Внимание» и кэшируется до нового расчёта. Необязательные структурные блоки без собственного правила не объявляются ошибками. Стаж проверяется отдельно по истории.

Контекстная панель показывает входящие/исходящие потоки и действия; подробности свёрнуты. Ширина панели регулируется, можно закрепить её рядом с картой. Контекстное меню, двойной клик, поиск по блоку/точному ID, Ctrl+K. Таблицы с поиском, сортировкой, страницами по 100 строк и экспортом текущей выборки. Рабочий режим ограничивает импульсы 12 крупнейшими маршрутами и выбранным, режим анимации — 100; линии сохраняются. Расчётный движок не менялся. Нужен браузерный тест на полном рабочем реестре.

## V4.10.1 — исправление загрузки Excel

CSP разрешает локальный SheetJS 0.18.5 вместо внешнего CDN. В основном интерфейсе также запрещены сетевые соединения; разрешены локальные скрипты, iframe и Worker. Снимки не шифруются. Алгоритм computeSets не изменён. Версии ресурсов обновлены для обхода старого кэша.

## V4.10.2 — закреплённая схема

Свободное перемещение всех карточек и сброс расположения удалены из настроек. Полотно и масштаб доступны. После создания нового блока в редакторе и успешного пересчёта появляется временный режим размещения только новых карточек в полной схеме. «Закрепить новые блоки» сохраняет положение локально; «Отменить размещение» или Esc возвращает автоматическое размещение. Перекрытие соседних карточек запрещено. При создании связи между существующими блоками они остаются неподвижными. Ранее сохранённые позиции не сбрасываются автоматически. Обзор и сравнение сохраняют собственную автоматическую компоновку. Движок и правила не изменены.

## V4.10.3 — подсветка направлений

Более яркие структурные связи и стрелки; импульсы в обзоре и полной схеме в обоих режимах производительности при включённых «Живых связях». В сравнении зелёные линии по-прежнему обозначают сопоставленные переходы, структурные импульсы ограничены ближайшими связями и приостанавливаются вместе с движением. Рабочий режим ограничивает структурные импульсы 24 линиями (8 в сравнении), фактические — 24 крупнейшими маршрутами и выбранным. Приоритет выбранных связей, учёт скрытых веток и reduced-motion. Положение карточек и расчёт не менялись.

## V4.10.4 — понятные изменения

В режиме «Изменения» одна компактная панель: пауза/движение, число отображаемых переходов, сводка и скачивание Excel. Дополнительные настройки доступны по шестерёнке. На схеме анимируются только подтверждённые по ID переходы; зелёные и красные стрелки на карточках показывают изменение состава блока, не предполагаемый маршрут. Все категории, маршруты и изменения по блокам доступны в сводке по всем направлениям; выборка реестра сохраняется. Excel содержит три листа: сводка, переходы и блоки. CSV со списком ID доступен отдельно. Расчётный движок и правила не изменены, экспорт локальный.

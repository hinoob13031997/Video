# NEON FLOW V2 — воронка умерших должников

Тестовая версия нового интерфейса, развёрнутая в репозитории **hinoob13031997/Video**.

Сайт: https://hinoob13031997.github.io/Video/

## Функции

- 49 блоков по структуре воронки из исходного `hinoob13031997/-`.
- Вертикальная схема, полная схема и режим сравнения.
- Анимированные переходы и просмотр внутренних ID, экспорт CSV.
- Поиск, фильтры по сумме/дате смерти (при наличии данных), масштаб, панель сведений.
- Чтение локального `data.bin` с двумя опубликованными снимками (если предыдущий содержится внутри) или двух отдельных `.bin/.json`.
- Чтение двух `.xlsx/.csv` с **явной принадлежностью договора к блоку**.
- Все загружаемые файлы обрабатываются локально в браузере: приложение не отправляет их на сервер.

## Локальный расчёт исходных Excel (новая интеграция)

Кнопка **Excel + правила** принимает таблицу правил и текущий исходный реестр, при необходимости предыдущий. Расчёт делегируется локальной копии оригинального движка в `engine.html`: исходное чтение больших XLSX, разбор таблицы правил, выборки, объединение баз и исключения сохранены. Если отсутствуют обязательные колонки, расчёт останавливается. Один реестр показывает число строк; для сравнения двух снимков используются уникальные внутренние ID. Движок не обращается к API GitHub, публикация данных отключена, сетевые запросы запрещены CSP (кроме загрузки библиотеки SheetJS с CDN как скрипта). Исходный сайт не изменяется.

**Статус проверки:** синтаксис и исходный код проверены. Два рабочих файла от 23–24 ноября пока не удалось открыть в среде проверки, поэтому совпадение результатов на них ещё не подтверждено. Требуется практическая проверка в браузере. Встроенные стартовые цифры — демонстрационные.

## Безопасность

**Этот репозиторий публичный.** Не коммитьте сюда настоящие реестры, внутренние ID, персональные данные, `data.bin`, `auth.json`, токены GitHub и прочую служебную информацию. Для проверки данных используйте кнопку локальной загрузки снимков в приложении.

## Развёртывание

GitHub Actions в `.github/workflows/pages.yml` автоматически публикует сайт из `main`. Все зависимости статические, сервер и сборка не требуются.

## Источники файлов

- `index.html`: разметка UI
- `styles.css`: тёмная неоновая тема и адаптивность
- `app.js`: интерфейс, визуализация, сравнение
- `jszip.min.js`: JSZip 3.10.1, MIT/GPLv3 (поставляется для локального чтения XLSX)
- `.github/workflows/pages.yml`: GitHub Pages

## V3 Premium

Обновлён визуальный слой поверх действующего движка: спокойная графитовая палитра, крупные карточки, полноширинная схема с выдвижной панелью деталей, три режима, список маршрутов, плавное движение только подтверждённого перехода, управление паузой и поддержка prefers-reduced-motion. Исходный расчётный движок engine.html и импорт файлов сохранены. Проверка эквивалентности расчёта на рабочих реестрах остаётся отдельной задачей.

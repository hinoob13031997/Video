# Moonvit — кинематографичная концепция сайта

Главная страница `index.html` адаптирует содержание moonvit.space в новый дизайн: вступление, шесть планет при прокрутке, рассказ о жевательном формате, каталог с фильтрами, карточки состава и покупки, ежедневный ритуал, отзывы, сотрудничество и вопросы.

## Запуск

Из `/workspace/Video`:

```sh
python3 server.py > /tmp/moonvit-server.log 2>&1
```

Установка зависимостей и сборка не требуются. Сервер поддерживает HTTP byte ranges для старой видеоверсии. Основной сайт — статический HTML/CSS/JavaScript. Все изображения локальные; Google Fonts необязательны, предусмотрены системные шрифты.

## Скролл и взаимодействие

Раздел `#journey` закрепляет сцену на время прокрутки шести глав. Скролл управляет смешиванием фонов, масштабом планет и появлением продуктов. Колесо мыши и вертикальные жесты не перехватываются. Навигация по планетам прокручивает страницу к соответствующей главе. Настройка `prefers-reduced-motion` отключает плавную анимацию.

Карточки открываются в нативном диалоге с составом и конкретными ссылками на товары Ozon/Wildberries. Escape закрывает диалог и возвращает фокус. Фильтры: все серии, баланс и сон, энергия, красота.

Содержание и ссылки сверены с moonvit.space. Цена 1500 ₽ взята с официального сайта и обозначена как его цена; актуальная цена зависит от продавца. Состав показан кратко, точная инструкция и дозировки остаются в карточках оригинальных товаров. Для Saturn учтён указанный на сайте кофеин. Отзывы приведены выдержками с указанием источника.

Фотографии всех шести банок взяты с официального сайта Moonvit и сохранены без изменения пикселей в `assets/products/`. Происхождение и SHA-256 файлов записаны в `assets/products/sources.json`. Прозрачные поля оригинальных файлов учитываются в CSS; этикетки не перерисовываются. По оригинальным этикеткам Земля — коллаген и биотин, Нептун — кожа, волосы и ногти. Вкусы Венеры (арбуз–личи) и Земли (персик–личи) приведены по выбранным фотографиям упаковок, поскольку тексты сайта описывают другие варианты.

Космические фоны в `assets/worlds/` созданы отдельно по кадрам видео. Скролл имеет фазы: общий план планеты, приближение и появление оригинальной банки, удержание крупного плана, переход через астероиды. Движение выполняется отдельными 2D-слоями, без 3D-моделей. Нативная вертикальная прокрутка сохранена; уменьшение движения отключает эффекты.

## Публикация

Адрес сайта: https://hinoob13031997.github.io/Video/.

Workflow `.github/workflows/pages.yml` публикует статические файлы при изменениях `main`. Если Pages ещё не включён, выберите Settings → Pages → Source: GitHub Actions и запустите workflow `Publish Moonvit website`.

Предыдущие варианты сохранены: `scenes.html` — переход к актуальному путешествию, `video.html` — исходный видеопрототип.

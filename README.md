# Moonvit — кинематографичная концепция сайта

Главная страница `index.html` адаптирует содержание moonvit.space в новый дизайн: вступление, шесть планет при прокрутке, рассказ о жевательном формате, каталог с фильтрами, карточки состава и покупки, ежедневный ритуал, отзывы, сотрудничество и вопросы.

## Запуск

Из `/workspace/Video`:

```sh
python3 server.py > /tmp/moonvit-server.log 2>&1
```

Установка зависимостей и сборка не требуются. Сервер поддерживает HTTP byte ranges для старой видеоверсии. Основной сайт — статический HTML/CSS/JavaScript. Все изображения локальные; Google Fonts необязательны, предусмотрены системные шрифты.

## Скролл и взаимодействие

Вступление и шесть глав объединены в одну закреплённую сцену `#journey`. В WebGL-варианте скролл двигает 3D-камеру между планетами через поле астероидов. Банка находится в глубине сцены и становится крупнее при приближении камеры; описание появляется после выхода продукта на передний план. Обратный скролл разворачивает маршрут. Колесо мыши и вертикальные жесты не перехватываются. Навигация по планетам прокручивает страницу к соответствующей главе. Настройка `prefers-reduced-motion` отключает плавную анимацию.

Карточки открываются в нативном диалоге с составом и конкретными ссылками на товары Ozon/Wildberries. Escape закрывает диалог и возвращает фокус. Фильтры: все серии, баланс и сон, энергия, красота.

Содержание и ссылки сверены с moonvit.space. Цена 1500 ₽ взята с официального сайта и обозначена как его цена; актуальная цена зависит от продавца. Состав показан кратко, точная инструкция и дозировки остаются в карточках оригинальных товаров. Для Saturn учтён указанный на сайте кофеин. Отзывы приведены выдержками с указанием источника.

Фотографии всех шести банок взяты с официального сайта Moonvit и сохранены без изменения пикселей в `assets/products/`. Происхождение и SHA-256 файлов записаны в `assets/products/sources.json`. Прозрачные поля оригинальных файлов учитываются в CSS; этикетки не перерисовываются. По оригинальным этикеткам Земля — коллаген и биотин, Нептун — кожа, волосы и ногти. Вкусы Венеры (арбуз–личи) и Земли (персик–личи) приведены по выбранным фотографиям упаковок, поскольку тексты сайта описывают другие варианты.

`flight.js` строит сцену на Three.js 0.186.1: объёмные планеты, кольца Сатурна, звёзды, астероиды, каменистая поверхность и движущаяся камера. Библиотека сохранена в `assets/vendor/three/` вместе с лицензией MIT, установка npm для запуска не нужна. Текстуры находятся в `assets/flight/`, происхождение файлов указано в `sources.json`. Для Луны и Земли использованы текстуры из официального репозитория Three.js; остальные поверхности и фон созданы по референсу. Оригинальные 3D-модели из видео не предоставлены: геометрия и материалы воссозданы, точного совпадения с роликом пока нет. У каждой планеты отдельное направление света и цвет атмосферы; кольца Сатурна наклонены по референсу, Нептун развёрнут вихрем к камере.

Оригинальная фотография банки располагается на плоскости в 3D-сцене: это сохраняет настоящие этикетки. При загрузке на GPU отсекаются только прозрачные поля, сами файлы в `assets/products/` остаются неизменными. Банка не является независимой объёмной моделью и не вращается вокруг своей оси.

Фазы каждой главы: подлёт к планете, появление банки из глубины, удержание крупного плана, пролёт к следующей планете. Рендер происходит при прокрутке и изменении окна, без непрерывного цикла в состоянии покоя. Для мобильных экранов ограничена плотность пикселей. Если WebGL недоступен, текстуры не загрузились или включено уменьшение движения, работает CSS-вариант с фонами из `assets/worlds/`. Эти фоны — кадры тех же 3D-моделей при подлёте и крупном плане, поэтому форма, материалы и освещение планет совпадают между режимами. Во время подлёта CSS-вариант смешивает два кадра; непрерывное движение камеры доступно в WebGL. После восстановления контекста WebGL возвращается автоматически. Последняя банка и её описание остаются видимыми до выхода из закреплённой сцены. Нативная вертикальная прокрутка сохранена.

## Проверка

При работающем сервере выполните `python3 tests/smoke.py`. Проверка использует Python Playwright и `/usr/bin/chromium`; они доступны в текущей облачной среде. Она проходит все шесть сцен и диалогов, обратную прокрутку, конец сцены Neptune, фильтры, пять размеров экрана, потерю и восстановление WebGL, уменьшение движения, отсутствие WebGL и ошибку загрузки текстуры. Для самой страницы эти инструменты не нужны.

`python3 tools/render-backdrops.py` пересоздаёт облегчённые фоны из текущего `flight.js` и записывает их контрольные суммы в `assets/worlds/sources.json`. Банки и текст в эти кадры не включены.

## Публикация

Адрес сайта: https://hinoob13031997.github.io/Video/.

Workflow `.github/workflows/pages.yml` публикует статические файлы при изменениях `main`. Если Pages ещё не включён, выберите Settings → Pages → Source: GitHub Actions и запустите workflow `Publish Moonvit website`.

Предыдущие варианты сохранены: `scenes.html` — переход к актуальному путешествию, `video.html` — исходный видеопрототип.
